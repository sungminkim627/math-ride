🚗 Math Ride
Math Ride is a fast-paced educational game where players drive a car and must quickly pick the correct arithmetic math answers by switching lanes before time runs out! This was my first-ever coding project, and I built everything from scratch—including the music. It was the project that sparked my passion for programming.

🎯 Features
✅ Lane-switching mechanics
✅ Increasing difficulty for an exciting challenge
✅ Randomized math questions for variety
✅ Custom-made music and visuals

🛠️ Technologies Used
Language: Processing (built on Java)
Graphics & Game Logic: Processing framework
Music & Sound: Composed and implemented by me

🕹️ How to Play
A math question appears on the screen.
Three lanes appear, each with a different answer.
Use the A key to move left and D key to move right.
Drive into the correct answer before time runs out!
The game gets faster over time, making it more challenging.

🚀 Lessons Learned
Creating Math Ride taught me the fundamentals of programming, game development, and creative problem-solving. It solidified my love for coding and led me to pursue more advanced projects in the future.
